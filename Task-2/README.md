# Exploratory Data Analysis (EDA)

## Objective
Analyze retail sales data to identify trends, patterns, and business insights.

## Tools Used
- Power BI
- Sample Superstore Dataset

## Data Cleaning
- Removed null values
- Checked data types
- Prepared dataset for analysis

## Visualizations
- Total Sales
- Total Profit
- Sales by Category
- Profit by Region
- Monthly Sales Trend
- Top Customers

## Key Insights
- Technology category generated the highest sales.
- West region generated the highest profit.
- Sales varied significantly across months.
- A small number of customers contributed a large portion of revenue.
