# Task 1 - Web Scraping

## Objective
Extract book information from a public website using Python web scraping techniques.

## Tools Used
- Python
- Requests
- BeautifulSoup
- Pandas

## Website
https://books.toscrape.com/

## Data Collected
- Book Title
- Price
- Availability

## Output
The scraped data is stored in books_data.csv.
