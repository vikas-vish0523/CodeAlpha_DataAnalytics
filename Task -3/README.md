# Data Visualization Dashboard

## Objective
To transform raw sales data into meaningful visual insights using Power BI.

## Tools Used
- Power BI
- Sample Superstore Dataset

## Dashboard Features
- Total Sales KPI
- Total Profit KPI
- Total Orders KPI
- Total Quantity KPI
- Sales by Category
- Profit by Region
- Monthly Sales Trend
- Category Distribution
- Segment Analysis
- Top Customers Analysis
- Interactive Filters

## Key Insights
- Technology category generated the highest sales.
- West region delivered the highest profit.
- Consumer segment contributed the most sales.
- Sales fluctuated across months.
- Top customers generated significant revenue.
